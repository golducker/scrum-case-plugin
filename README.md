# scrum-case

Skills for an Agile/Scrum team case competition: 25 MCQs plus a scenario case study submitted as `.docx` within 120 minutes, in English.

## Install

```powershell
claude plugin marketplace add golducker/scrum-case-plugin
claude plugin install scrum-case@scrum-case-local
```

## Use

- `/scrum-case:scrum-case` with the case pasted in: timed walkthrough mapped to the rubric. Say "mock round" to practise.
- `/scrum-case:scrum-mcq`: drill or answer multiple-choice questions.
- `/scrum-case:humanizer`: remove AI writing patterns from a draft.

Check the competition rules on AI tools before using this in a live assessment. `.docx` export relies on the separate built-in docx skill.
